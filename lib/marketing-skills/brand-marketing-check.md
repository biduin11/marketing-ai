# brand-marketing-check

# Чекер согласованности «Бренд vs Маркетинг»

## Основа фреймворка (Ashley Hansberger / Motto®)

- **БРЕНД** — кто вы есть: смысл, идентичность, долгосрочная история, восприятие компании/эксперта целиком.
- **МАРКЕТИНГ** — как о вас узнают: продвижение, каналы, форматы, ROI, краткосрочные метрики.
- Рассинхрон между ними → непоследовательный голос → потеря доверия аудитории.

7 шагов выравнивания: ядро бренда → инструменты → общие цели → коллаборация → системы → двойная аналитика → ревизия.

## Когда применять

- Перед публикацией поста, карусели, сценария, рекламного текста
- При подготовке КП или продающего сообщения для клиента
- При квартальном аудите контент-стратегии (полная проверка по 7 шагам)

## Что нужно на входе

1. **Профиль бренда субъекта** — личный блог или конкретный клиент. Если профиля ещё нет в `brand-profiles/`, сначала заполни его вместе с пользователем по `_template.md`.
2. **Контент на проверку** — текст/сценарий
3. **Канал и формат** (Instagram-карусель, Telegram-пост, КП, таргет и т.д.)
4. **Маркетинговая цель** (охват / лиды / продажи / доверие / удержание)

## Алгоритм анализа

### 1. Соответствие ядру бренда
Где контент звучит «как мы», а где — нет. Указывай конкретные фрагменты текста как доказательство, не общие слова.

### 2. Маркетинговая эффективность
Подходит ли формат каналу, насколько сильный оффер/hook/CTA для заявленной цели.

### 3. Риски рассинхрона
Конкретные фразы или посылы, которые могут прозвучать «не нашим голосом», подорвать доверие или противоречить долгосрочному позиционированию ради сиюминутной выгоды.

### 4. Рекомендации
Конкретные правки — как сохранить маркетинговую силу, но усилить brand-alignment. Не общие советы, а готовые формулировки.

### 5. Вердикт
- 🟢 Соответствует бренду и эффективен для канала
- 🟡 Эффективен, но нейтрален/рискован для бренда — нужна доработка
- 🔴 Рассинхрон — переписать до публикации

## Аудит по 7 шагам (для кампаний/квартальных проверок)

Для каждого шага отметь: ✅ выровнено / ⚠️ частично / ❌ разрыв — и где именно.

1. Ядро бренда — зафиксировано и понятно команде?
2. Инструменты — каналы/форматы соответствуют тому, кто вы есть?
3. Общие цели — маркетинг и «бренд-видение» работают на одно и то же?
4. Коллаборация — все, кто создаёт контент, говорят одним голосом?
5. Системы — есть гайдлайны/шаблоны, закрепляющие согласованность?
6. Двойная аналитика — измеряется и восприятие бренда, и ROI маркетинга?
7. Ревизия — когда последний раз пересматривали соответствие?

## Структура профилей

```
brand-profiles/
  _template.md       — шаблон для нового субъекта
  my-blog.md          — личный блог (черновик, требует доработки)
  <client-slug>.md     — профиль клиента
```
